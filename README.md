Using a sample.txt file, both program calculates word statistics of the file and prints it. text_analyzer.py is a refactored version of unpythonic_analyzer.py. A sample.txt file is needed to run both programs program.

Features:

read_file() now uses with to open the file

find_word_count() uses a dictionary comprehension

find_long_words() uses a list comprehension

print_word_info() uses f for concatenation 

Output:

Total number of words, unique word count, the five most frequent words, and the number of long words.
